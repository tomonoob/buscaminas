# 💣 Buscaminas JS

El clásico **Buscaminas** creado en JavaScript vanilla. Despeja el tablero usando lógica y pistas numéricas.

🎮 **[Jugar en vivo](https://tomonoob.github.io/buscaminas/)**

## 🕹️ Características
* **Lógica Matricial:** Generación dinámica de minas y números adyacentes.
* **Expansión Automática:** Algoritmo recursivo para despejar zonas vacías.
* **Controles:** Clic izquierdo (revelar) y clic derecho (bandera).
